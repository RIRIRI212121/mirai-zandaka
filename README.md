# みらい残高

銀行残高から「まだ引き落とされていないクレジットカード利用分」を先に差し引いた、**今日の実質残高**を見せるための家計・シフト管理アプリ（バイトをする学生向け）。

## 動いているファイル

- 本体は `index.html.html` の1ファイル（HTML＋インラインCSS/JS）。`app.js` と `style.css` は現在読み込まれていない旧ファイルである。

## 残高の定義（仕様）

- **みらい残高 = 推定銀行残高（今日）− 未引き落としのクレカ利用分**
- 残高を入力すると、その日が「基準日」として自動保存される。以後は基準日の翌日〜今日に口座へ反映された収支だけを加減算する（過去分の二重計算を防ぐため）
- 推定銀行残高 = 基準残高 ＋ 反映済み収入・給与 − 反映済み支出（現金支出、引き落とし済みのクレカ・サブスク）
- 未引き落としのクレカ利用分は、利用日が基準日より前のものも含めて全額差し引く
- **未払い給与（働いたが給料日がまだの分）はメイン残高に含めず**、「◯月◯日払い予定 ¥X」として別枠表示する。今後のサブスク引落も別枠表示のみ
- 引き落とし日・給料日は、その当日には口座反映済みとして扱う

## 日付の設定（仮置き）

シフト画面の ⚙️（給料・勤務設定）で変更できる。現在の既定値は仮置きであり、実際の勤務先・カードの日付が判明したら差し替えること。

| 項目 | 既定値 |
|---|---|
| 給与の締め日 | 月末 |
| 給料日 | 締めの翌月25日 |
| クレカの締め日 | 月末 |
| クレカの引き落とし日 | 締めの翌月27日 |

## 時給の決まり方

- 基本は設定の「基本時給（平日）」と「土日祝の時給」で自動判定する。祝日判定には振替休日・国民の休日を含む（近似）
- シフト入力の時給欄に金額を入れると、その日のシフトだけその時給が優先される。空欄なら自動判定

## データの保存先

- ブラウザの localStorage（`mirai-iphone-master-data` と `mirai-shift-settings-master`）
- 設定画面からJSONでバックアップ／復元ができる。復元時は形式チェックと確認を行い、復元前のデータは `mirai-iphone-master-data-pre-restore` に控えが自動保存される
